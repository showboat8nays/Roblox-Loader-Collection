## FAQ

### What is XCutors?

XCutors is a collection of popular Roblox executor tools packaged together with a universal loader for convenient access and use on Windows.

### Is it safe to use?

These tools are third-party software. While we provide the latest versions, users should always exercise caution, understand the risks, and use them at their own discretion, adhering to Roblox's Terms of Service.

### Which executor should I use?

Each executor has unique features. Volt and Synapse Z are known for stability and performance, while Potassium and Wave offer different script support and interfaces. We recommend trying each via the universal loader to see which fits your needs.

### Does this require a key or subscription?

XCutors itself is a free package. However, the individual executors included (like Synapse Z) are commercial products and may require their own separate purchase or subscription.

### How do I update the executors?

The universal loader will check for updates automatically. You can also visit the GitHub Releases page to download the latest version of the entire XCutors package.

### My anticomponent is blocking the loader. What should I do?

Some security software may incorrectly flag tools of this nature. You may need to create an exception or whitelist the XCutors folder in your anticomponent settings.

### Are there plans for more executors?

The collection may be updated with additional tools in the future based on popularity and developer requests. Watch our GitHub repository for announcements.

### Can this be used for Roblox Studio development?

This package is designed for runtime script execution within Roblox games, not for development or testing within Roblox Studio.
